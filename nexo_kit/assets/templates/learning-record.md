# Registro de aprendizaje

Contenido recomendado para una memoria candidata del proyecto:

- Afirmación concreta: qué aprendimos.
- Condiciones: cuándo se aplica y cuándo no.
- Evidencia: reproducción, comando, archivo o ID comprobado.
- Razonamiento: por qué la alternativa falló o por qué se eligió esta solución.
- Caducidad: cambio de versión, contrato o contexto que obligaría a revisarla.
- Estado: hipótesis, candidato comprobado o regla aprobada.

Guarda el registro con memory add y su fuente. Antes de aprobar o promover, comprueba la evidencia y busca duplicados. No inventes una causa para que el registro parezca completo. Una mejora candidata de instrucciones no debe instalarse silenciosamente como regla global.
