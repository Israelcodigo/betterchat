# Contrato de tarea

Plantilla de contenido para --description de task add. Completa solo campos útiles; esta copia no es otra fuente de estado.

| Campo | Contenido requerido |
|---|---|
| Resultado | Comportamiento que cambia y para quién |
| Alcance | Módulos o archivos afectados y propiedad del trabajador |
| Aceptación | Observaciones que distinguen éxito y fallo |
| Verificación | Comando, escenario o inspección por criterio |
| Dependencias | IDs de tareas cuyo resultado se necesita |
| Incógnitas | Lo que no sabemos y experimento para averiguarlo |
| Límites | Efectos fuera del alcance y presupuesto de reparación |

La descripción debe permitir decidir qué entregar. Una dependencia fallida no satisface un prerrequisito. Cuando se altere un contrato, explica el motivo y conserva las decisiones vigentes.
